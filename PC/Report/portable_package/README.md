# Temperature & Humidity Report Generator

## Что это?
Программа для создания отчетов по температуре и влажности из CSV файлов датчиков.

## Как пользоваться?

### Простой способ (двойной клик):
1. Положите ваш CSV файл в эту же папку
2. Запустите `run_report.bat`
3. Следуйте инструкциям на экране

### Продвинутый способ (командная строка):
```
TempHumidityReporter.exe ваш_файл.csv месяц год [опции]
```

**Примеры:**
```
TempHumidityReporter.exe sensor_data.csv 8 2025
TempHumidityReporter.exe office_temp.csv 9 2025 --output September_Report.docx
TempHumidityReporter.exe data.csv 12 2024 --template my_template.docx
```

### Параметры:
- `csv_file` - путь к CSV файлу с данными
- `month` - номер месяца (1-12)
- `year` - год
- `--output` - имя выходного файла (необязательно)
- `--template` - путь к шаблону DOCX (по умолчанию template.docx)
- `--verbose` - подробный вывод

## Формат CSV файла:
```
TIME;TEMP;HUM;DEV
"Thu, Aug 21 2025 14:27";23.5;45;ESP32
```

## Что программа делает:
- Читает данные датчиков из CSV
- Фильтрует рабочие дни (воскресенье-четверг)
- Находит данные в 08:00 и 16:00 (±15 минут)
- Усредняет 3 ближайших показания
- Проверяет соответствие нормам (20-26°C, 40-60%)
- Создает красивый отчет в Word с цветовым кодированием

## Требования:
- Windows 7/10/11
- Файл template.docx в той же папке
- CSV файл с данными датчиков

## Проблемы?
- Убедитесь, что template.docx в той же папке
- Проверьте формат вашего CSV файла
- Убедитесь, что указали правильный месяц и год

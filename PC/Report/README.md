# Temperature and Humidity Report Generator

Автоматическая генерация отчетов о соответствии температуры и влажности требованиям на основе CSV данных.

## Описание

Программа анализирует CSV файлы с данными датчиков температуры и влажности и генерирует DOCX отчеты с таблицами соответствия требованиям:
- Температура: 20-26°C
- Влажность: 40-60%
- Рабочие дни: воскресенье-четверг
- Время измерений: 08:00 и 16:00

## Формат входных данных

CSV файл должен содержать колонки:
```
TIME;TEMP;HUM;DEV
Thu, Aug 21 2025 14:27;24.4;64.3;HT_3C71BF28FBD8
Thu, Aug 21 2025 14:37;24.5;66.5;HT_3C71BF28FBD8
```

Где:
- `TIME` - время в формате "Thu, Aug 21 2025 14:27"
- `TEMP` - температура в градусах Цельсия
- `HUM` - влажность в процентах
- `DEV` - идентификатор устройства

## Использование

### Базовый пример
```bash
python main.py data.csv 8 2025
```
Генерирует отчет за август 2025 года из файла `data.csv`.

### Расширенные опции
```bash
python main.py sensor_data.csv 12 2024 --output December_2024.docx --template my_template.docx
```

### Параметры командной строки

- `csv_file` - путь к CSV файлу с данными
- `month` - месяц (1-12)
- `year` - год
- `--template` - путь к шаблону DOCX (по умолчанию: template.docx)
- `--output` - имя выходного файла (по умолчанию: автогенерация)
- `--verbose` - подробный вывод

## Алгоритм работы

1. **Парсинг CSV** - загрузка и преобразование данных из CSV файла
2. **Фильтрация** - отбор данных за указанный месяц и рабочие дни
3. **Поиск точек** - нахождение ближайших измерений к 08:00 и 16:00
4. **Усреднение** - расчет среднего по 3 ближайшим точкам (если доступны)
5. **Проверка соответствия** - сравнение с требованиями
6. **Генерация отчета** - создание DOCX файла с таблицей

## Особенности

### Поиск данных около целевого времени
- Ищет до 3 ближайших измерений в пределах 15 минут от целевого времени
- Рассчитывает среднее значение температуры и влажности
- Если данных нет - ячейка отмечается как "-"

### Цветовое кодирование
- 🟢 Зеленый фон - значения в норме
- 🔴 Красный фон - значения вне нормы  
- ⚪ Серый фон - данные отсутствуют

### Форматирование
- Температура: `%0.1f` (например, 24.5)
- Влажность: `%0.0f` (например, 55)

## Поддерживаемые форматы дат

В шаблоне поддерживаются следующие паттерны:
- `yyyy` - год (2024)
- `yy` - год (24)
- `MMMM` - полное название месяца (January)
- `MMM` - короткое название месяца (Jan)
- `MM` - месяц двузначный (01)
- `M` - месяц (1)
- `dddd` - полное название дня (Monday)
- `ddd` - короткое название дня (Mon)
- `dd` - день двузначный (01)
- `d` - день (1)
- `ww` - номер недели ISO (35)

## Требования к шаблону

Шаблон DOCX должен содержать:
- Заголовок с текстом "Temperature and humidity monitoring"
- Таблицу с колонками: Humidity, Temperature, Time, Date
- Соответствующие заголовки и нижние колонтитулы

## Решение проблем

### CSV файл не найден
```
Error: CSV file not found: data.csv
```
Убедитесь, что путь к файлу указан правильно.

### Шаблон не найден  
```
Error: Template file not found: template.docx
```
Создайте файл template.docx или укажите правильный путь через `--template`.

### Нет данных за месяц
```
Error: No data found for specified month
```
Проверьте, что в CSV файле есть данные за указанный месяц и рабочие дни.

### Некорректный формат CSV
```
Error parsing row: {...}
```
Проверьте формат CSV файла и кодировку (должна быть UTF-8).

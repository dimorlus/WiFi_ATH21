"# WiFi AHT21 - Система мониторинга температуры и влажности

🌡️ **Полноценная IoT система для сбора, передачи и визуализации данных температуры/влажности**

Проект представляет собой комплексное решение для мониторинга микроклимата, состоящее из датчиков на базе ESP8266, серверной части для сбора данных и клиентских приложений для визуализации.

## 🏗️ Архитектура системы

```
[ESP8266+AHT21] --WiFi/MQTT--> [MQTT Broker] <--MQTT-- [PC Logger] --CSV--> [Визуализаторы]
      ^                                                                           ^
      |                                                                           |
 [Web Config]                                                              [Web Dashboard]
```

## 🚀 Быстрый старт

### 1. Настройка ESP8266 устройства
```bash
# Прошивка через Production/ESP/
cd Production/ESP
espprog_last_fw3.cmd  # Редактировать COM порт
```

### 2. Запуск сборщика данных
```bash
cd PC/mqtt_logger
# Настроить config.ini (MQTT брокер, топики)
./build.sh  # или Build.bat на Windows
./mqtt_logger
```

### 3. Веб-визуализация
```bash
cd PC/HT_WebView
npm install
npm run dev  # Разработка
npm run build  # Продакшн
```

## 🌐 MQTT Топики

Формат: `<base_topic>/<device_mac>/<suffix>`

| Топик | Направление | Назначение |
|-------|-------------|-----------|
| `/HUMT` | ESP → Logger | Данные датчика (время, T°, RH%, точка росы) |
| `/alive` | ESP → Logger | Статус устройства |
| `/INF` | ESP → Logger | Информация о системе |
| `/CFG` | Logger → ESP | Запросы конфигурации |
| `/FOTA` | Logger → ESP | URL для OTA обновления |

## 📊 Формат данных CSV

```csv
TIME;TEMP;HUM;DEV
Mon, Jan 01 2024 14:30;23.5;65.2;Living Room
Mon, Jan 01 2024 14:31;23.6;65.1;Living Room
```

## ⚙️ Конфигурация

### ESP8266 (через Web UI на IP устройства)
- Wi-Fi настройки (SSID/пароль)
- MQTT брокер (хост, порт, пользователь)
- SSL/TLS уровень безопасности
- Часовой пояс и имя устройства

### PC Logger (config.ini)
```ini
[mqtt]
broker = localhost
port = 1883
topic_pattern = +/+/HUMT

[parser]
time_format = %a, %b %d %Y %H:%M
csv_format = TIME;TEMP;HUM;DEV
```

## 🔋 Энергопотребление

- **Deep Sleep**: ~20 мкА (требует GPIO16→RST)
- **Light Sleep**: ~1 мА (с сохранением RAM)
- **Рабочий режим**: ~80 мА (Wi-Fi активен)

Типичный цикл: 30 сек работа → 10 мин сон

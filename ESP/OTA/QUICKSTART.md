# ESP8266 OTA Script - Краткая справка

## Быстрый старт

```bash
# По IP адресу
python esp_ota_updater.py 10.0.1.166

# По имени устройства (НОВОЕ!)
python esp_ota_updater.py HT_3C71BF29A3EC

# Через CMD wrapper
quick_ota.cmd HT_3C71BF29A3EC
```

## Основные возможности

✅ **Умный поиск** - автоматически находит ESP по имени или IP  
✅ **MAC извлечение** - получает MAC из имени `HT_XXXXXXXXXXXX`  
✅ **Многоуровневый поиск** - ARP → MAC → сканирование сети  
✅ **Автоматизация** - HTTP сервер + telnet команды  
✅ **Информация о файлах** - размер, дата изменения  

## Параметры

| Опция | Описание | По умолчанию |
|-------|----------|--------------|
| `esp_address` | IP или имя ESP | - |
| `--http-port` | HTTP порт | 80 |
| `--firmware-dir` | Каталог прошивок | `../mqtt_aht21/bin` |

## Файлы

## Поиск устройств

**Формат имени**: `HT_3C71BF29A3EC` (HT_ + MAC без разделителей)  
**Алгоритм**: ARP проверка → MAC поиск → сетевое сканирование  
**Скорость**: ~2-5 секунд для полного поиска

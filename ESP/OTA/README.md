# ESP8266 OTA Update Script

Автоматизированный скрипт для обновления прошивки ESP8266 по воздуху (Over-The-Air) с умным поиском устройств по имени или IP.

## 🚀 Основные возможности

- **Умный поиск устройств**: Автоматическое определение IP по имени устройства
- **Извлечение MAC из имени**: Поддержка формата `HT_XXXXXXXXXXXX`
- **Многоуровневый поиск**: ARP таблица → MAC поиск → сканирование сети
- **HTTP сервер**: Автоматическая раздача файлов прошивки
- **Telnet автоматизация**: Отправка команд OTA/FOTA
- **Информация о файлах**: Отображение размера, даты изменения

## 📋 Требования

- Python 3.6+
- Windows (использует `arp` и `ping`)
- ESP8266 с поддержкой telnet команд

## 🎯 Использование

### По IP адресу (классический способ)
```bash
python esp_ota_updater.py 10.0.1.166
```

### По имени устройства (новый способ!)
```bash
python esp_ota_updater.py HT_3C71BF29A3EC
```

### С кастомными параметрами
```bash
python esp_ota_updater.py HT_3C71BF29A3EC --http-port 8000 --firmware-dir "C:\firmware"
```

### Через CMD wrapper
```bash
quick_ota.cmd HT_3C71BF29A3EC
```

## 🔧 Параметры командной строки

| Параметр | Описание | По умолчанию |
|----------|----------|--------------|
| `esp_address` | IP адрес или имя ESP устройства | - |
| `--esp-port` | Telnet порт ESP | 23 |
| `--http-port` | HTTP порт для файлов | 80 |
| `--firmware-dir` | Каталог с прошивками | `../mqtt_aht21/bin` |
| `--local-ip` | Локальный IP (автоопределение) | auto |

## 🧠 Алгоритм поиска устройств

1. **Определение типа адреса**
   - IP формат (xxx.xxx.xxx.xxx) → использование напрямую
   - Любой другой формат → поиск по имени

2. **Поиск по имени** (выполняется последовательно):
   
   **a) Проверка ARP таблицы по имени**
   ```
   arp -a | findstr "device_name"
   ```
   
   **b) Извлечение и поиск по MAC**
   ```
   HT_3C71BF29A3EC → 3C71BF29A3EC → 3c-71-bf-29-a3-ec
   arp -a | findstr "3c-71-bf-29-a3-ec"
   ```

## ⚡ Быстрый старт

1. **Убедитесь, что ESP доступен в сети**
2. **Узнайте имя устройства** (обычно отображается в роутере как `HT_XXXXXXXXXXXX`)

- Убедитесь, что ESP включен и в сети
- Проверьте, что telnet порт 23 открыт
- Убедитесь, что HTTP порт не занят

## Устранение проблем

### Проблема: "Ошибка telnet соединения"
- Проверьте IP адрес ESP8266
- Убедитесь что ESP в режиме telnet setup
- Проверьте сетевое подключение

### Проблема: "Порт занят"
- Используйте другой порт: `--http-port 8000`
- Проверьте запущенные процессы: `netstat -an | findstr :80`

### Проблема: "Файлы прошивки не найдены"
- Проверьте путь: `--firmware-dir ./путь/к/файлам`
- Убедитесь что файлы называются `user1.bin` и `user2.bin`

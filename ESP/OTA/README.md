# ESP8266 OTA Update Automation

Автоматизированный инструмент для обновления прошивки ESP8266 по воздуху (OTA). Поддерживает как автоматический, так и ручной режимы работы.

## Особенности

- ✅ **Автоматическое определение IP адреса** компьютера
- ✅ **Автоматическая отправка команд** OTA и FOTA через telnet
- ✅ **Ручной режим** для пошагового контроля
- ✅ **HTTP сервер** с многопоточностью для раздачи прошивки
- ✅ **Гибкая настройка** портов и каталогов

## Использование

### Автоматический режим (рекомендуется)
```bash
python esp_ota_updater.py 10.0.1.166
```

Скрипт автоматически:
1. Определит ваш IP адрес
2. Запустит HTTP сервер на порту 80
3. Подключится к ESP по telnet
4. Отправит команды `OTA=http://IP:80` и `FOTA`
5. ESP загрузит и установит прошивку

### Ручной режим
```bash
python esp_ota_updater.py 10.0.1.166 --manual --http-port 8000
```

В ручном режиме скрипт только запустит HTTP сервер и покажет команды для ручного выполнения.

### Полные параметры
```bash
python esp_ota_updater.py <ESP_IP> [OPTIONS]

Позиционные аргументы:
  ESP_IP                IP адрес ESP8266 (например: 10.0.1.166)

Опции:
  --esp-port PORT       Telnet порт ESP (по умолчанию: 23)
  --http-port PORT      HTTP порт для файлов (по умолчанию: 80)
  --firmware-dir DIR    Каталог с прошивкой (по умолчанию: ./firmware)
  --local-ip IP         Локальный IP (автоопределение если не указан)
  --manual              Ручной режим - только HTTP сервер
```

## Процесс обновления ESP8266

1. **ESP подключается по telnet** на порт 23
2. **Отправляется приглашение**: `Telnet setup`
3. **Команда OTA**: `OTA=http://IP:PORT` → ответ `OK`
4. **Команда FOTA**: `FOTA` → ответ `OK`
5. **ESP загружает прошивку**: HEAD и GET запросы к user1.bin
6. **Установка завершена**

## Требования

- **Python 3.6+** (стандартная библиотека, без внешних зависимостей)
- **Файлы прошивки** `user1.bin` и/или `user2.bin` в указанном каталоге
- **Доступ к ESP8266** по сети (telnet порт 23)

## Устранение проблем

### Проблема: "Ошибка telnet соединения"
- Проверьте IP адрес ESP8266
- Убедитесь что ESP в режиме telnet setup
- Проверьте сетевое подключение

### Проблема: "Порт занят"
- Используйте другой порт: `--http-port 8000`
- Проверьте запущенные процессы: `netstat -an | findstr :80`

### Проблема: "Файлы прошивки не найдены"
- Проверьте путь: `--firmware-dir ./путь/к/файлам`
- Убедитесь что файлы называются `user1.bin` и `user2.bin`

## Notes
- Ensure your firewall allows incoming connections to the HTTP server port (default: 80).
- The script auto-detects the local IP address to use in the OTA URL.
- For custom port or advanced options, see script help: `python ota_server.py --help`

Привет! А можешь мне помочь сделать скрипт для OTA апдейта прошивки ESP8266? 
Скрипт (или программа, я не знаю как это лучше назвать) должна поднимать http 
сервер, к которому бы мог подключиться ESP чтобы скачать один из двух лежащих 
в неком каталоге файла user1.bin и user2.bin. Для этого надо по указанному при 
запуске скрипта сетевом адресе ESP  (ну например 10.0.1.166:23) открыть что-то вроде 
telnet 10.0.1.166
Появится
Telnet setup
там "набрать" (тут 10.0.1.200 - адрес компьютера, с которого запускается скрипт, 
хорошо бы, чтобы он его определял сам)
OTA=http://10.0.1.200:80
увидеть ответ 
OK
тогда набрать 
FOTA
тоже появится 
OK
и после этого, по задумке, ESP подключится к указанному URL и закачает нужный ему файл.

Я запускаю руками
